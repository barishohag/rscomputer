# RS Computer POS

A browser based point of sale and shop operations app for RS Computer. It includes sales, customer dues, cash reconciliation, pending orders, shop settings, and JSON backup/export.

## Deploy on Vercel

Import this repository in Vercel. It is a plain static HTML app: choose the **Other** framework preset and leave the build command and output directory empty.

## Data and access

This public repository contains an empty starter register; workbook customer names and sales records are not included. New records are stored in the current browser's local storage and do not sync across devices.

Before sharing a Vercel deployment URL, enable Vercel Authentication protection in the project settings. The app itself does not implement a password login or a shared database.
